# Freebeat plugin

Create music videos, dance videos, and animated lyric videos from your songs inside your AI agent. Also create original music, images, short video clips, singing photos, and lip-sync videos.

The plugin connects to the hosted Freebeat MCP server at `https://freebeat.ai/api/mcp` and adds skills that guide the agent through each workflow.

## Install

- **Cursor:** open **Customize → Marketplace**, find **Freebeat**, and select **Add**. Sign in with your Freebeat account when asked.
- **Any MCP client:** add a remote MCP server with the URL `https://freebeat.ai/api/mcp`. Sign-in uses OAuth; no API key is needed.

## Account and credits

You need a Freebeat account. Generations use the credits in your Freebeat account at the same rates as https://freebeat.ai, and the agent asks before any step that spends credits. Videos usually take 15–60 minutes.
